# Mundo Café
Página web simple de una tienda de café ficticia. Fue creada como práctica de HTML y CSS.

# Contenido del proyecto
- `index.html`: página de inicio.
- `productos.html`: cards de productos (Flexbox).
- `resenas.html`: reseñas de clientes (Grid).
- `ubicacion.html`: mapa de Google Maps (iframe) (W.I.P)
- `contacto.html`: formulario de contacto con Formspree. (W.I.P)
- `styles.css`: estilos compartidos por todas las páginas.
